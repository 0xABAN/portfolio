## One-liner

The site **is a desktop**: wallpaper, icons, overlapping windows, taskbar. Retro classic-OS energy (Win9x/XP-era cues), restyled to our palette — not a pastel anime skin clone of the ref.

## Pillars

1. **Desktop as IA** — sections are apps/windows, not scroll sections only.
2. **Retro chrome** — title bars, window controls, icon grid, start/task affordances.
3. **Living shell** — drag, stack, min/max/close; the desktop moves, it isn’t a poster.
4. **Layered mess (controlled)** — intentional overlap and depth; still usable.
5. **Portfolio payload** — real bio/work/projects inside the windows.

## Do

- Classic window frames (title bar, min/max/close affordances)
- Desktop icons that open content
- Taskbar / start-style entry point
- Hard-ish UI geometry; pixel or near-pixel borders OK
- Black / light gray structure with red as signal

## Don't

- Flat SaaS landing with fake “window” CSS only on one card
- Copying the ref’s lavender/pastel kawaii skin wholesale
- Inscrutable UI with no way to reach content
- Heavy 3D skeuomorphism that fights the web stack

## Steal from ref

From [moodboard](../raw/moodboard-desktop.md):

- Icon column on the desktop
- Multiple window types (media, image, dialog, list)
- Taskbar with running apps + clock
- Big cursor / playful hit targets OK
