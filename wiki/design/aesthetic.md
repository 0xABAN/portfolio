## One-liner

A personal site that feels like a **boot screen you can scroll** — terminal chrome, grain, ASCII, and hard black/red/white contrast. Not a soft modern portfolio.

## Pillars

1. **TUI / BIOS frame** — monospace UI chrome, tab rows, status lines, bordered panels ([ref 02](../raw/moodboard-02.md)).
2. **Brutalist poster density** — big type, thin red rules, technical labels, HUD ornaments ([ref 01](../raw/moodboard-01.md)).
3. **2000s net energy** — pixel/ASCII portraits, scanlines/noise optional, raw not polished.
4. **Image + glyph** — photographs and ASCII share the stage; neither is decoration-only.

## Do

- Monospace as the default voice for chrome and body
- Hard edges, 1px borders, boxed regions
- Red as signal (active, alert, accent line) — never pastel
- White for primary type on black
- ASCII blocks, box-drawing, pseudo-HUD glyphs
- Slight grain / CRT feel if cheap in CSS

## Don't

- Soft gradients, glassmorphism, rounded "friendly" cards
- Multi-hue palettes (no cyan/green/purple drift from refs)
- Stock SaaS spacing and Inter-on-white
- Motion that feels app-like (prefer blink, scan, glitch ticks)
