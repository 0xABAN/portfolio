Content is organized as **desktop apps**, not a long single article (though a window may scroll inside).

## App map (draft)

| App / icon | Window content |
| --- | --- |
| About | Bio, portrait, short links |
| Work | Roles / timeline list |
| Projects | Project list or folder → detail windows |
| Contact | Email, socials, maybe a “mail” compose toy |
| Media (opt) | Music/video player chrome for showreel |
| Trash (opt) | Joke / easter egg |

Names can get personality later; structure matters more than labels.

## Tone

Human, brief, a little playful — matches retro desktop whimsy without drowning info.

## Media

- Photos and graphics live in windows (viewer / frame)
- Icons should read at small size (simple shapes, red/gray/black)
