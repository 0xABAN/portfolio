## Tone

Short, direct, slightly machine. Labels over paragraphs. Think boot log + human one-liners, not LinkedIn about-me.

Examples of voice:

- `// adam — systems / product / build`
- `STATUS: ONLINE`
- section headers as mono tabs or `01_WORK`

## Likely sections (draft, not locked)

| Section | Notes |
| --- | --- |
| Boot / hero | Name, role line, ASCII or photo portrait |
| About | Few lines + image or glyph block |
| Work / exp | List or cards-as-panels, red markers |
| Projects | Title, one-liner, media thumb or ASCII stand-in |
| Contact | mailto / links as menu entries |

Reorder freely; keep the **chrome consistent** across sections.

## Media mix

| Kind | Use |
| --- | --- |
| Photos | Real work/life shots; monochrome or hard contrast preferred; red frame |
| ASCII / pixel art | Portrait, logos, decorative breaks; white on black |
| Icons | Prefer text glyphs over colorful SVG sets |

## Interaction flavor (optional later)

- Blinking block cursor
- Typewriter lines on first paint (keep subtle)
- Tab focus styles that look like TUI selection

Not required for v1 scaffold.
