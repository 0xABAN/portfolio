## What it is

Full-viewport **classic desktop**: icon rail, overlapping windows (portrait “broadcast”, paint/editor, dialog, file list, media player), taskbar with Start + running apps + clock. Soft lavender/pink skin in the original.

## Steal

- Desktop metaphor as the whole page
- Icon grid + labeled launchers
- Heterogeneous window types
- Taskbar / Start / clock chrome
- Layered composition on first paint

## Leave / remap

- Pastel lavender shell → [black / light gray / red](../design/color.md)
- Anime/character IP specifics — not our content
- Unreadable clutter — we need clear portfolio paths
